# The Compendium PKM System
this is an obsidian vault PKM template
tailerd for knowledge workers, including developers and personal use

it uses the ZettleKasten note taking method

## Setup
1. clone this repo
2. move the [🐧The Compendium 🐧]() folder to your preferd vault directory
3. open it up with obsidian
4. read the **Tutorial** note in order to know how to use it

## Features
- ZettleKasten first
- kanban plugin and native vim/helix keybinding support
- it comes with over 50 preinstalled themes
