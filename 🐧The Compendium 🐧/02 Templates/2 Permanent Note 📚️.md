>**What is it**
>a permanent note is the default note type, it is used to write about any topic/thing there is in an organized, final, way.
>
>examples: summories/reviews, lists, taking note of something, ideas, etc 
>but it can be used for anything there is, it's the default note type.
>- the key points are:
>	- it must be the final version
>	- it must be organized
>	- it must be atomic (meaning you write everything you need to)
